Expediente documental de la simulación local realizada con Social-Engineer Toolkit.

- `Actividad04_Reporte_Juan_Francisco_Ortega.pdf`: informe final de 31 páginas.
- `Actividad04_Reporte_Juan_Francisco_Ortega.docx`: versión editable.

## Seguridad

El expediente utiliza únicamente un sistema y credenciales ficticios. No contiene el portal funcional, configuración operativa de SET, logs ni XML reutilizables. La práctica se ejecutó exclusivamente en `127.0.0.1` y el servicio fue detenido al finalizar.
