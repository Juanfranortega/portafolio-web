# Actividad 03 - No presiones Esc... todavía

Carpeta de evidencias de Juan Francisco Ortega Jiménez para la Actividad 03 de Fundamentos de Ciberseguridad.

Incluye:

- Presentación editable en PowerPoint y vista previa en PDF.
- Código fuente completo en ZIP, emisor para Windows y receptor para Kali Linux.
- Consigna original de la actividad.
- Capturas de red, ejecución, envío y persistencia del registro.

La página principal de la evidencia se encuentra en `evidencias/parcial-1/actividad-03.html`.

Ejemplos: `reporte.pdf`, `captura-01.webp`, `codigo-fuente.zip`.
