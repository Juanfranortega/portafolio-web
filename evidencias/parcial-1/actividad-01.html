Parcial 01 · Actividad 01

Aquí comienza mi portafolio

Diseño, implementación y publicación de la estructura base del portafolio digital de CNO IV – Seguridad Informática mediante tecnologías web nativas.

  • Estado: documentada
  • Tipo: desarrollo web
  • Publicación: GitHub Pages
  • Protocolo: HTTPS

01 / OBJETIVO

Objetivo de la actividad

Diseñar, implementar y publicar la portada técnica de un portafolio académico funcional, accesible y correctamente organizado. El sitio debe identificar al estudiante y a la asignatura, explicar su propósito, presentar el perfil académico, documentar su construcción e incluir navegación, contacto, pie de página y conexión segura.

02 / DESARROLLO

Procedimiento realizado

  1. Se analizó la consigna y cada indicador de la rúbrica para convertirlos en componentes verificables.
  2. Se estructuró el contenido con HTML5 semántico: encabezado, navegación, presentación, perfil, evidencias, tecnología, contacto y pie de página.
  3. Se desarrolló una identidad visual formal inspirada en un expediente digital de ciberseguridad, con composición responsiva y temas claro y oscuro.
  4. Se añadió JavaScript para menú móvil, pestañas por parcial, tema, progreso de lectura, navegación activa y animación progresiva.
  5. El proyecto se versionó en GitHub y se publicó mediante GitHub Pages con una URL pública protegida por HTTPS.

03 / RESULTADOS

Resultado obtenido

Se obtuvo un sitio web nativo, adaptable a computadora y teléfono, con identidad académica completa, navegación clara y estructura preparada para registrar actividades de los tres parciales. La página está publicada, el repositorio conserva el código y la sección técnica explica su lógica general.

04 / REFLEXIÓN

Aprendizaje y reflexión

Esta actividad me permitió relacionar el desarrollo web con prácticas de organización, accesibilidad y seguridad. Comprendí que una evidencia profesional no consiste únicamente en mostrar un resultado: también debe explicar el proceso, facilitar su verificación y mantener una estructura clara para poder evolucionar durante el curso.
